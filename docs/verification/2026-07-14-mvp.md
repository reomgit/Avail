## Signing and release status

The locally inspected artifact is ad hoc signed, sandboxed, and hardened. `codesign --verify --deep --strict` passes. Gatekeeper rejection of this local artifact is expected because it is not Developer ID signed or notarized.

The tag-triggered workflow and `Scripts/notarize.sh` are implemented but were not submitted to Apple because Developer ID and App Store Connect credentials were not available. Before public distribution, configure the secrets documented in `docs/releasing.md`, run the workflow on a stable macOS/Xcode runner, and require successful notarization, stapling, and `spctl` assessment.

## Known MVP limitations

- PDFs require selectable text; OCR is not included.
- DRM-protected or encrypted EPUBs are rejected.
- Narration currently uses installed macOS voices through the pluggable local `NarrationEngine`; downloadable local neural-model providers remain a post-MVP extension.
- SwiftSoup is temporarily pinned to its merged `8333684` workaround for a Swift 6.4 optimizer ownership crash. Return to a tagged dependency after SwiftSoup publishes a release containing that fix.
- On this macOS 27/Xcode 27 beta, AppKit logs transient negative-geometry runtime faults when opening or switching a SwiftUI Settings `TabView`. The same faults reproduce in an isolated app containing only Apple’s documented `Settings { TabView { Form } }` pattern, with no visible malfunction. Recheck on the stable release toolchain; this is not observed as an Avail-specific layout failure.
- ZIPFoundation emits a dependency-manifest warning about its deprecated watchOS 4 declaration under Swift 6.4; Avail is macOS-only and the warning does not affect the built product.

No tag, push, GitHub repository creation, or public release was performed.
